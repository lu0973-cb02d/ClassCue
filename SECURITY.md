# Security Policy

## Supported version

Security fixes are currently made on the latest commit of the default branch.

## Reporting a vulnerability

Please do not include API keys, signing files, passwords, recordings, classroom transcripts, or other personal data in a public issue. Report the minimum reproducible technical details through a private GitHub security advisory when available.

The project stores configured AI API keys through Android Keystore, but users are still responsible for selecting a trusted HTTPS endpoint and protecting their device and backups.
