本版本是 0.2.8 的维护更新，识别、提醒、录音和 AI 相关的代码都没有改动。

## 隐私

- 换新手机时的设备间迁移现在也不会带走课堂历史数据库。此前只有云备份排除了它，设备迁移规则漏掉了，与说明不符。数据库的 `-wal`、`-shm`、`-journal` 旁路文件也一并排除。
- 录音和 API Key 一直被排除在云备份与设备迁移之外，没有变化。

## 安装包

- 安装包缩小约 4.7 MiB（85.45 → 80.78 MiB）：不再打包 sherpa-onnx 自带的两个 C/C++ API 原生库，应用从不加载它们。

## 升级

- 0.2.8 由 CI 临时生成的证书签名，本版本的签名证书与它不同，因此不能直接覆盖安装 0.2.8。请先在“历史记录”中导出需要保留的录音和 Markdown，卸载 0.2.8 后再安装本版本。卸载会同时删除应用内的记录和录音。

## 验证

- 107 项 JVM 单元测试通过（新增 3 项备份规则测试，云备份、设备迁移和旧版备份规则都必须排除历史数据库、API Key 存储和录音）。
- Android Lint 0 个错误，警告和提示数与 0.2.8 相同。
- 公开版 APK 构建成功。移除原生库后的中/大档离线识别只做了静态检查（原生库的依赖关系和加载路径），尚未在真机上验证；如果中/大档识别无法启动，请反馈。
