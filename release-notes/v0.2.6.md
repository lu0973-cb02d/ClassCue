## 课堂识别与手表通信

- 恢复华为 Lite Wearable 手表端源码，并在手机端接入 Wear Engine，可向已配对手表发送课堂提醒和 AI 答案。
- 设置页增加手表开关、包名、HAP 签名指纹和直连测试入口；未配置正式 HAP 指纹时会安全阻止发送。
- 手表源码、签名前校验脚本和 SDK 完整性校验已随源码公开；正式 HAP 仍需使用开发者自己的 DevEco 工具链与签名材料构建。

## 远场识别与稳定性

- 延长结束课堂时的识别收尾，避免最后一段老师讲话丢失。
- 识别队列改为有界等待与背压，减少高负载下静默丢帧。
- 放宽远场低音量门控，改善 Magic8 Pro 等手机在远距离场景的可用输入。
- 收紧“先叫名后提问”的弱信号判定，降低吐字不清和普通课堂话语造成的误报。
- Markdown 导出改为流式写入，长期课堂记录导出更稳。

## 使用提示

- 本 APK 是 Android Debug 签名测试包，不能覆盖安装其他证书签名的正式包。
- 手表端需要正式签名 HAP、配对设备和真机回归；本 Release 不包含签名 HAP。
- 远场识别仍受距离、回声、口音和麦克风采集能力影响，请在实际课堂中逐步验证。
